📜 Platform Rules & Privacy Policy

1. About Web App Platform

Nex Profit is a smart investment ecosystem utilizing decentralized Cloud Mining configurations. Users fund their accounts across multi-tiered VIP configurations to receive consistent, computational hourly and daily algorithmic returns.

2. Principal Investment Rule

⚠️ Critical Regulation: Once a user commits funds to any VIP Tier package, the principal investment amount cannot be withdrawn under any circumstances before the 45-day active contract cycle expires. However, accumulated daily interest/returns can be withdrawn securely at any given time.

3. Daily Tasks Configuration

To authorize and push server rewards to your main balance, users must actively initialize the computational verification task once every 24 hours. The active mining node verification session lasts exactly 1 minute.

4. Deposit Guidelines

All deposits must be completed via designated Telebirr routes using valid Transaction ID (Txn ID) references. The administrative team reviews and authorizes pending requests within a maximum window of 24 hours, automatically upgrading accounts based on the deposited tiers.

5. Withdrawal Protocols

The system enforces a minimum individual withdrawal limit of 500 ETB. To maintain maximum security against account takeovers, bank details are permanently locked upon initial setup. Validated payouts are dispatched within 24 hours.

6. Data Privacy & Systems Security

All sensitive credentials and payment routes are heavily locked via Supabase security vault layers. Operating multiple accounts per individual is strictly prohibited and results in immediate automated machine bans.
